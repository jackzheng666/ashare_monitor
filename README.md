# A股短线行情监控系统（实验性）

使用 AKShare / 东方财富公开行情、启发式短线选股、行业板块、个股新闻及 OpenAI GPT API 的 Streamlit 网页工具。
**不是交易所授权低延迟行情，不是实盘自动交易系统。**

## Mac 安装
```bash
cd ashare_monitor
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -U pip
pip install -r requirements.txt
cp .env.example .env
```
打开 `.env`，加入你的 `OPENAI_API_KEY`（别提交 GitHub）。模型在 `.env` 的 `OPENAI_MODEL` 配置，需要你的 API 账户实际可用。

## 两个终端运行
终端 A（必须常驻）：
```bash
source .venv/bin/activate
python collector.py
```
终端 B：
```bash
source .venv/bin/activate
streamlit run app.py
```
浏览器打开 Streamlit 给出的 `http://localhost:8501`。测试：`pytest -q`。

## 现有项目集成
为保护你的旧 `quant_predictor_v2`，这个包独立运行。先把整个文件夹放在 `~/vscode/` 下验证。通过 `data/snapshot.csv` 和 `data/ranked.csv` 可以对接你现有的模型或特征工程。不要覆盖旧的 `src/data_fetcher.py`，避免原来的 `peer_benchmarks` 导入错误再次影响运行。

## 数据机制和风险
- 交易时段（上海时区）：工作日 09:30–11:30、13:00–15:00。**尚未接入中国交易日历**，节假日必须人工识别；工作日不一定开盘。节假日即使误判为盘中，页面显示的采集时间也不能证明报价有效。
- 全市场快照默认每 180 秒，非交易时段每 15 分钟；具体完整抓取可能耗时较长。源接口返回的是抓取时间，不是交易所撮合时间；**需要在东方财富客户端核对报价**。
- 采集失败不覆写最后一份股票快照，状态会变为 `error`，AI 按盘中分析按钮被禁用。板块独立容错。启动后先等首次成功采集。
- 数据接口存在限制、反爬和字段更改风险；检查终端错误后升级 `akshare` 或更换正式授权数据源。免费公网源不适合秒级交易。
- 主板候选预筛选排除 ST、退市和部分新股代码，默认不覆盖创业板、科创板、北交所；因此“全市场”是**全市场抓取、主板优先筛选**，不是所有股票都能获得排序。可在 `src/screener.py` 修改规则。
- 简单新闻模块按候选股票获取最多5条新闻；**不是完整的政策新闻数据库**，新闻可能过时、缺漏或错误。需要独立核实发布日期与发布主体。
- 前复权K线用于均线研究，但行情快照为真实成交价，两者有分红送股造成的口径偏差；不能直接用复权支撑位下单。
- 没有A股完整节假日日历、涨跌停价格/ST规则复核、停牌处理、实时盘口、成交费用/滑点模型、回测与幸存者偏差消除，因此系统仅适用于研究和观察。
- 默认 AI 每天最多调用10次，且每次额外收费；空KEY能使用非AI模块。网络/API自动重试最高2次，但尝试在调用前即扣除本地配额，避免故障反复产生费用。不得公开 `.env`。
- T+1、整手100股、涨跌停、盘中急速波动和滑点可能使建议不可执行。不要照 AI 结果自动下单。

## 生产化下一步
1. 使用受支持且有合法授权的数据服务，并校验行情交易所时间戳和交易状态。
2. 接入权威A股交易日历，设置日内行情更新序号及异常价检验。
3. 所有股票补全停牌/ST/上市日期/涨跌停板规则；对行业板块做完整资金成交额排名。
4. 政策新闻改成来自交易所、证监会、上市公司公告及权威媒体的有来源抓取，去重和发布时间比对。
5. 建立可复现实盘前回测（交易成本、买入延迟、涨跌停无法成交、数据时间一致性），再考虑纸面模拟交易。
